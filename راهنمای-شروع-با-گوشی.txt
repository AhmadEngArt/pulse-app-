PULSE — نسخه وب قابل نصب (PWA)

این نسخه برای پیش‌نمایش روی گوشی ساخته شده است:
- ساخت گروه و رویداد
- ثبت پاسخ اولیه به رویداد
- انتخاب حس/پالس (فعلاً نمایشی)
- ذخیره اطلاعات روی همان مرورگر گوشی
- پوسته قابل نصب و کش اولیه برای استفاده آفلاین پس از اولین بارگذاری

محدودیت مهم:
این نسخه هنوز حساب کاربری، همگام‌سازی بین گوشی‌ها، دعوت و تأیید اعضا، ارسال واقعی پالس و اعلان Push ندارد. داده‌ها با پاک شدن داده‌های مرورگر ممکن است از بین بروند. فایل‌ها باید روی یک میزبان HTTPS منتشر شوند تا نصب PWA و Service Worker فعال شود.

مسیر استفاده فقط با گوشی:
1) فایل ZIP را از حالت فشرده خارج کن.
2) پوشه را در یک مخزن GitHub بارگذاری کن (با مرورگر گوشی).
3) در Settings مخزن > Pages، گزینه Deploy from a branch را انتخاب کن و branch اصلی و پوشه root را ذخیره کن.
4) پس از انتشار، لینک HTTPS سایت را در Chrome اندروید باز کن.
5) از منوی Chrome گزینه Install app یا Add to Home screen را بزن.

این روش برای نمایش نسخه اولیه است، نه راه‌اندازی محصول نهایی. برای انتشار واقعی باید امنیت، بک‌اند، ورود کاربران، قواعد دسترسی و اعلان‌ها اضافه و آزمایش شوند.
