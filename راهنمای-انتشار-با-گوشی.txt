PULSE — راهنمای انتشار فقط با گوشی اندروید

این پوشه برای انتشار روی GitHub Pages آماده شده و workflow انتشار خودکار دارد.

۱) ساخت مخزن
- در Chrome وارد https://github.com شوید و وارد حساب خود شوید.
- از منوی + گزینه New repository را بزنید.
- نام مخزن را pulse-app بگذارید.
- برای شروع می‌توانید Public را انتخاب کنید (کد عمومی می‌شود؛ هیچ کلید یا رمز محرمانه‌ای داخل این نسخه نیست).
- Create repository را بزنید.

۲) بارگذاری فایل‌ها از گوشی
- فایل ZIP را در برنامه Files / My Files گوشی Extract کنید.
- وارد مخزن تازه شوید و Add file > Upload files را بزنید.
- همه فایل‌ها و پوشه‌های داخل پوشه PULSE_PWA_phone را انتخاب و بارگذاری کنید؛ خود پوشه مادر را به‌عنوان یک پوشه تو در تو بارگذاری نکنید.
- اگر انتخاب پوشه در مرورگر گوشی دشوار بود، از Chrome گزینه Desktop site را فعال کنید.
- پایین صفحه Commit changes را بزنید.

۳) فعال‌کردن Pages
- وارد تب Settings مخزن شوید.
- از بخش Pages، اگر لازم بود Source را روی GitHub Actions بگذارید.
- به تب Actions بروید و اجرای Deploy PULSE to GitHub Pages را بررسی کنید.
- بعد از سبز شدن اجرای workflow، آدرس سایت در بخش Deployments یا Settings > Pages نمایش داده می‌شود.

۴) نصب روی گوشی
- آدرس HTTPS را با Chrome اندروید باز کنید.
- منوی سه‌نقطه را بزنید و Install app یا Add to Home screen را انتخاب کنید.

نکات مهم
- انتشار عمومی یعنی فایل‌های رابط کاربری و کد این نسخه برای همه قابل مشاهده‌اند؛ اطلاعات خصوصی کاربران را در این نسخه وارد نکنید.
- اطلاعات فعلی فقط در حافظه همان مرورگر می‌ماند و بین دستگاه‌ها همگام نمی‌شود.
- Push notification، ثبت‌نام واقعی، مدیریت اعضا و دعوت هنوز به بک‌اند متصل نشده‌اند.
- این نسخه یک نمونه آزمایشی است؛ قبل از استفاده عمومی باید احراز هویت، مجوزها، قواعد امنیتی و اعلان‌ها پیاده‌سازی و تست شوند.
